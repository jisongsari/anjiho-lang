# 똥랭

경기과학고에는 전설의 **42기 안지호**가 서식한다. 
2025년 2학기 전설의 관측천문학 수업에서 학생들이 떠들자 박기현 선생님께서 떠든 사람이 누구냐고 물어보셨고, 이에 부산 출신 배선우는 강력한 부산 사투리로 **안지호입니다~**라고 답했다. 이 날 이후로 **안지호입니다~**는 관측천문학 유행어가 되었다. 무언가 사건이 발생했을 때 실제 원인과 관계없이 **안지호입니다~**를 외치는 것이 하나의 밈이 되었다. 이에 박기현 선생님께서는 특유의 억양으로 "안!지!호! 입니다!"라고 외치시며 새로운 버전이 탄생하였다. 현재는 42기 전체에 퍼져 두 버전이 모두 사용된다.

똥랭은 **양지성의 지랄똥싸기 프로젝트**의 일환으로 안지호를 놀리기 위해 만든 난해한 프로그래밍 언어다. [엄랭](https://github.com/rycont/umjunsik-lang)에서 글자만 바꿔 제작했으며, 문법은 엄랭과 아주 유사하다.

웹용 엄랭 처리기의 코드를 이용해 [웹-똥랭 처리기](https://anjiho-lang.wolilab.com)를 만들었다. 이곳에서 똥랭 코드를 실행할 수 있다.

```
진짜

안지!
아안지!

어푸아!똥... ....

안아,
아안아아.

똥.. ...
지아아?

입니다!
```

# 문법

똥랭은 "안", "지", "호", "어푸" 네 개의 키워드와 `?`, `.`, ` `, `~`, `똥` 다섯 개의 기호로 이루어진다. 모든 프로그램은 `진짜`로 시작하며, 항상 `입니다!`로 끝나야 한다.

## 자료형

정수: 온점과 반점의 개수로 나타낸다. 온점 하나당 1을 더하고, 반점 하나당 1을 뺀다.

```
... => 3
.. => 2
,, => -2
,,, => -3
.,., => 0
```

## 연산자

- 1 증가: `.`
- 1 감소: `,`
- 곱하기: ` ` (공백)

```
.. => 2
,, => -2
., => 0
.. .. => 4
.. ,, => -4
... ... ... => 27
```

## 변수

변수는 정수 인덱스로 접근하고 대입한다. 지정하지 않은 변수의 기본값은 0이다.

### 대입 (안)

`안` 앞에 붙은 연음(`아`)의 개수가 변수의 인덱스이고, `안` 뒤에 오는 수가 대입할 값이다.

```
아아안 => 3번째 변수에 0 지정
아안 => 2번째 변수에 0 지정
안.. => 1번째 변수에 2 지정
아안. => 2번째 변수에 1 지정
안,,, => 1번째 변수에 -3 지정
```

### 사용 (아)

`아`의 개수번째 변수를 불러온다.

```
아 => 1번째 변수
아아 => 2번째 변수
아아아 => 3번째 변수
```

## 콘솔

### 지! (입력)

콘솔에서 정수를 입력받는다.

```
안지! => 콘솔 입력을 받아 1번째 변수에 대입
아안지! => 콘솔 입력을 받아 2번째 변수에 대입
```

### 지? (정수 출력)

콘솔에 정수를 출력한다.

```
지..? => 콘솔에 2 출력
지아? => 콘솔에 1번째 변수 출력
```

### 지호 (문자 출력)

`지`와 `호` 사이에 오는 정수를 유니코드 문자로 변환해 콘솔에 출력한다. 사이에 정수가 없으면 개행한다 (`지호` => `\n`).

```
지........... ........호 => 콘솔에 X 출력
```

## 지시문

### 어푸!

`어푸{정수}!{실행할 명령}` 형태로 쓴다. 정수가 0이면 명령이 실행되고, 그렇지 않으면 다음 줄로 넘어간다.

### 똥

`똥` 뒤에 오는 정수번째 줄로 이동한다 (`똥.. => 2번째 줄로 이동`). 원라인 코드에서는 `~`로 분리된 단위로 카운트한다.

### 응가

`응가` 뒤에 오는 정수를 반환하며 프로그램을 종료한다.

## 기타

- 확장자는 `.dung`이다.
- One-line으로 작성할 때는 `\n` 대신 `~`로 구분한다.

# 예제

## "안!지!호! 입니다!" 출력

문자 출력은 `지{유니코드값}호` 형식이라, 한글 한 글자를 출력하려면 5만 개 가까운 점을 찍어야 한다. 곱셈(공백)과 변수를 활용해 점의 수를 줄였다.

2번 변수에 `4*113*113 = 51076`을 저장해두고 `입(51077)`을 출력할 때 변수에서 1만 더한다. 3번 변수에는 `214*214 = 45796`을 저장해 `다`를 그대로 출력하고, `니(45768)`는 같은 변수에서 28을 뺀다.

```
진짜
아안.... ................................................................................................................. .................................................................................................................
아아안...................................................................................................................................................................................................................... ......................................................................................................................................................................................................................
지...................................................................................................................................................................................................................... ............................................................................................................................................................................................................................................호
지... ...........호
지................................................................................................................................................................................................ .............................................................................................................................................................................................................................................................................호
지... ...........호
지........................................................................................................................ .........................................................................................................................................................................................................................................................................................................................................................................................................................................................................호
지... ...........호
지.... ........호
지아아.호
지아아아,,,,,,,,,,,,,,,,,,,,,,,,,,,,호
지아아아호
지... ...........호
입니다!
```

## 두 정수의 합 출력

콘솔에서 정수 두 개를 입력받아 합을 출력한다. 한 식 안에서 변수 두 개를 더할 방법은 없으므로, 첫 번째 값을 1번 변수에 저장한 뒤 두 번째 입력을 거기에 더한다.

```
진짜
안지!
안아지!
지아?
입니다!
```

`안지!`는 입력 1을 1번 변수에 대입하고, `안아지!`는 `1번 변수 + 입력 2`를 다시 1번 변수에 대입한다.
